🚀 PASOS PARA EMPEZAR:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  OBTENER API KEY DE GOOGLE GEMINI
    Visita: https://makersuite.google.com/app/apikey
    - Haz clic en "Create API Key"
    - Copia la clave generada

2️⃣  CONFIGURAR LA API KEY
    Opción A (Recomendado - Variables de entorno):
    $ export GEMINI_API_KEY="tu_api_key_aqui"
    
    Opción B (Para desarrollo - archivo .env):
    Crea un archivo .env en /WAVAULT/backend/ con:
    GEMINI_API_KEY=tu_api_key_aqui

3️⃣  INSTALAR DEPENDENCIAS (ya están instaladas!)
    pip install -r requirements.txt
    
    Si faltan:
    pip install librosa numpy scipy google-generativeai

4️⃣  VERIFICAR SETUP
    bash test-analyze-beat-ai.sh

5️⃣  USAR EL SCRIPT
    Opción 1 - Python directo:
    $ python3 analyze_beat_ai.py /ruta/audio.mp3
    
    Opción 2 - Con API Key inline:
    $ GEMINI_API_KEY="tu_key" python3 analyze_beat_ai.py audio.mp3
    
    Opción 3 - Con Node.js:
    const analyzer = new AudioAIAnalyzer();
    analyzer.analyze('audio.mp3').then(result => console.log(result));

Análisis Local (sin API):
  • Detección de BPM (Tempo)
  • Extracción de Tonalidad (Key)
  • Análisis Espectral
  • Determinación Mayor/Menor
  • Clasificación por género (basada en BPM)

Análisis con IA (Gemini API):
  • Inferencia de Mood/Sentimiento
  • Generación de 5 Tags descriptivos
  • Contexto musicológico avanzado
  • Análisis profesional de productor musical

Performance:
  • Tiempo: 3-5 segundos por canción
  • Precisión BPM: ±5%
  • Formatos: MP3, WAV, FLAC, OGG
  • Límite: 120 segundos (optimizable)

Node.js/Express:

  const analyzer = new AudioAIAnalyzer();
  const result = await analyzer.analyze('beat.mp3');

cURL:
  curl -F "file=@beat.mp3" http://localhost:3000/api/analyze-beat

JavaScript Frontend:
  const formData = new FormData();
  formData.append('file', audioFile);
  
  const response = await fetch('/api/analyze-beat', {
    method: 'POST',
    body: formData
  });
  const result = await response.json();
  console.log(result.ai_inference.mood);

→ Verifica que tienes internet
→ Verifica que API Key es válida
